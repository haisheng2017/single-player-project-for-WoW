# 20261004 通灵学院补丁

## 1. 六扇教室门：击杀后关死

**文件**：`mangos-classic/src/game/AI/ScriptDevAI/scripts/eastern_kingdoms/scholomance/instance_scholomance.cpp`、`scholomance.h`

**原**：老师进战、死亡、脱战时 `DoUseDoorOrButton` 拨动门。门从关的状态开始时，进战拨成开、死亡再拨回关，人被关死在房间里（阿雷克斯·巴罗夫实测复现）。

**改后**：新增 `UseClassroomDoor`，只在房间 `m_bIsActive` 为假时生效——进战 `UseOpenableObject(false)` 强制关，死亡或脱战 `UseOpenableObject(true)` 强制开。`m_bIsActive` 为真（院长暗影传送占用该房间）时不碰门。

**不动的**：`HandlePortalEvent` 整段保持原样（传送关、清完复生守卫开、单只脱战 FAIL）。

## 2. 博学者普克尔特：不被小怪呼救串进战斗

**文件**：
- `mangos-classic/src/game/Entities/Creature.h`
- `mangos-classic/src/game/Grids/GridNotifiers.cpp`
- `mangos-classic/src/game/AI/BaseAI/CreatureAI.cpp`
- `classic-db/Updates/4839_c.10901_no_respond_assist.sql`

**原**：同阵营 5 码链式呼救，尸体小怪（10480/10481）一节节把 10901 叫进战斗，拉最远的怪也会带出 boss，房间打不了。

**改后**：新增 `CREATURE_EXTRA_FLAG_NO_RESPOND_ASSIST = 0x00040000`。进战搜人（`AnyAssistCreatureInRangeCheck`）和接到呼救（`HandleAssistanceCall`）两处都跳过带此标志的怪。SQL 只给 10901 加位。

**不动的**：10480/10481 仍互相呼救；走到 boss 身边视野照常接战；boss 自己进战后仍可呼救。

## 生效方式

重编 `mangosd`（`make mangosd && make install`）；SQL 导入 `classicmangos` 后 `.reload creature_template` 或重启。
