## 2. 机制底座（五门闩一架，全部出厂就位）

1. **副本入口 = `areatrigger_teleport` 的条件列**。原生带条件的门：MC 窗（3528/3529，50+任务 7848）、BWL（3726，50+任务 7761）、Naxx（4156 入/4156 配套 4055 出，51+任务 9378）、奥妮（2848，50+**护符 16309**）。**无任务的门**：祖格 3928、AQ20 4008、AQ40 4010、**厄运之槌六门 3183/3184/3185/3186/3187/3189（全 45 级——东主门/东后门/西门/西便门各是独立触发器）**。85 号对"该关的门"统一 `required_level` 抬 **61**（60 封顶世界无人可过，可逆），开放回原值。**玛拉顿 3133/3134 与一切 5 人本从不修改**（玛拉顿官方 P1 就在场，其余 5 人本不在任何分幕的门控里——两家皆照历史）。
2. **战场 = `battleground_template` 三行的存废**（1=奥特兰克/2=战歌/3=阿拉希，本库恰三行）。核心没有每战场开关——**行不在=模板不建=排队永不弹出**，玩家与 **bot 双侧干净失效**（bot 对缺失模板判空，无需动 aiplayerbot.conf）。P3 归 AV+WSG、P4 才补 AB——**这是 2019 服的真实分幕**（历史注：原版 AB 本来就与祖格同补丁）。
3. **世界 boss = `creature` 两行的存废**：卡扎克（guid 2723，entry 12397，诅咒之地）、艾索雷葛斯（guid 52349，entry 6109，艾萨拉）；重生 48-96h。**绿龙四王出厂就没有 spawn 行**（模板+脚本在而无人放它们出场——P4 演出日是你的戏）。
4. **事件族 = `game_event` 的 `occurence` 档**（0=永久禁用，核心把档期推到 2100；开放=回各族出厂档）。与分幕相关的五族（出厂档核自数据行）：**元素入侵 11/13/38/39（火/水/土/气，4320）→P2**；**战场周 18/19（奥特兰克/战歌，30240）→P3**、**20（阿拉希，30240）→P4**；**马戏团 4/5/23/26/28/37（86400）→P3**；**钓鱼大赛 14/15/34（10080）→P4**。AQ 五阶段 120-124、天灾 17/89-99 属 SERVERSIDE 核心驱动，脚本从不动。
5. **命令面**：`.event start/stop/list`（SERVERSIDE 事件经 start 后由角色库 `game_event_status` **跨重启续跑**；⚠️ 保留号 **987=直接触发停服重启**，别手滑）；`.worldstate wareffort/scourgeinvasion`（管理员级，AQ 与天灾的导演台）；`.reload config` / `.server restart 30`（docs/15 §2）。

> 节日类事件（仲夏/冬幕/新年/万圣等）**按日历自跑、不进分幕**——2019 官方同样如此（首年冬幕节落在 P2 期间只因十二月到了）。竞技场宝箱赛（事件 16）同理属开服内容，P1 起照常。`Edge of Madness`（29-32）只在祖格内部生效——ZG 开门前一并在后台空转，无外显。

> bot 侧零开工是设计出来的：随机 bot 对未激活事件的 spawn 判"不存在"，对缺失战场模板判"无此战场"——**关世界内容，bot 一起遵守**。

## 9. 85 号脚本 · 用法与快照契约

```bash
bash scripts/85-set-phase.sh --dry-run all       # 预演六阶段全部 SQL（零落库）
bash scripts/85-set-phase.sh <1-6>               # 切阶段（首跑自动快照）
bash scripts/85-set-phase.sh --restore           # 从快照完全还原（幂等 INSERT IGNORE）
# 凭据约定与 40/70 号同流：MYSQL_HOST/PORT/USER/PASS（缺省静默提示）、WORLD_DB（默认 classicmangos）、WOW_ROOT
```
- **声明式幂等**：每次运行写的是目标阶段的全量期望状态——直跳不漏开关、重跑无副作用；**角色库零写入**（角色/装备/任务/副本进度/荣誉一概不碰），任何阶段 `--restore+重启` 都能回出厂。
- **首跑先快照**（真实执行的第一次）：四张受影响表的相关行 →`run/backup/phase-snapshot.sql`（存在永不覆盖）+ 幂等还原卷。期间手工的演出（P4 放的绿龙等）不属快照——另行 mysqldump（docs/15 §3）。
- **生效面**：入口条件/BG 模板/spawn/事件档期都在启动时装载 → **切完 `.server restart 30`**。
- 85 号**只发 SQL 与提示**：不碰 conf/模块/bot 配置；P4 绿龙与 P5/P6 的导演戏是手册教的游戏内演出（分幕归脚本、演出归人）。
